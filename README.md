# Dice Game

A simple console game written in C#. You play against the computer by rolling dice.

## Features
* **Random Rolls:** Generates a random number from 1 to 6 for you and the computer.
* **Winner Check:** Compares the numbers and announces the winner.
* **Auto Re-roll:** Automatically rolls the dice again if it is a tie.
* **Replay Option:** Asks if you want to play another round after the game ends.

## What I learned in this project
* How to use the `Random` class to generate random numbers.
* How to control game flow using nested `while` loops.
* How to write logical conditions using `if-else` (Imperative Programming).
